## Die sechs Prüfrunden — was die Wellen-Recherche zunehmend sauberer macht

Alle Runden fanden ausschließlich **Text-/Zitatfehler**, nie einen Fehler im Datenkern. Die
Fehlerklasse war immer dieselbe: **Negativaussagen über OpenStreetMap**, die nicht am Objekt
geprüft waren.

| Runde | Befunde |
|---|---|
| 1 | fünf falsche OSM-Negativa, drei falsche OSM-Tag-Zitate, zwei tote Deep-Links, eine tote Impressums-URL, eine malformierte URL (`…/****`), eine falsche Distanz, eine unzutreffende NorthData-Historie |
| 2 | eine weitere falsche Negativa (Pickert — der Betriebspunkt `way 1562018071` existiert), eine **Textkorruption durch die eigene Korrektur**, eine neu erzeugte Falschaussage („Weiterleitung auf city-map.com“ — 404 **ohne** Weiterleitung), zwei tote Links, eine falsche Impressums-Attribution, unvollständige Hausnummern-Aufzählungen, ein ungenauer Domain-Befund, drei Dubletten-Vermerke |
| 3 | zwei **live falsche Negativa, die als „präzisiert“ etikettiert waren** (Lichtenow 22A existiert, Wittenberg 2 existiert), eine falsche Beschreibung von looker.de, eine unzutreffende „tot“-Markierung einer live erreichbaren Quelle, die doppelte Satzkonstruktion, zwei unvereinbare Hausnummern-Aussagen, weitere unmarkierte tote Links |
| 4 | eine falsche Selbstauskunft („zweimal **wortgleich**“ — es gab nie ein wortgleiches Paar) und eine nicht abrufbare Quellen-URL (`api/0.6/map` ohne `bbox`, HTTP 400) |
| 5 | zwei live falsche Negativa (Wittenberg `way 163622391` **existiert**; Lichtenow: die genannte Fremdadresse gehörte zu einem anderen Dossier), eine unzutreffende Historieaussage, eine zu pauschale Gate-Begründung |
| 6 | ein harter Blocker: die **Korrektur** der Negativa war selbst falsch — der zitierte Kartenausschnitt enthielt die Lead-Adresse gar nicht (Lichtenow: longitude 13.9068491 < 13.9085; Hameln: 52.1212 > 52.1200) — plus zwei Präzisionsbefunde (eine falsche Distanz, eine unzutreffende „zentriert“-Formulierung) |

**Lehre:** Eine Negativa-Aussage ist erst belastbar, wenn die **Hausnummer** live geprüft ist —
ein Straßen-Reverse genügt nicht; und ein Kartenausschnitt muss das behauptete Objekt
**tatsächlich einschließen**. Die Welle wurde deshalb für die 00:00-Welle mit beiden Fallen als
kompakter Warnung an die Recherche-Agenten weitergegeben.
